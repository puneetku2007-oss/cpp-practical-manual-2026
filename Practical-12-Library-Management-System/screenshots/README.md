# Screenshots

No terminal screenshots were captured when this project was built (it was developed and tested in a
command-line environment without a screen). The actual program output is stored as text instead:

- [`../docs/sample-console-output.txt`](../docs/sample-console-output.txt) - a full demo session
- [`../docs/test-transcripts/`](../docs/test-transcripts/) - one real transcript per automated test

To add real screenshots, run `./build/library` in your own terminal, take a screenshot of each scenario
(add / display / search / issue / return / error cases) and save the images in this folder.
